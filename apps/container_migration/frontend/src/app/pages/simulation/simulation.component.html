vuln-spring scale control

Select a cluster and scale `vuln-spring` like in Migration tab controls.

Only works where a Kubernetes Deployment named vuln-spring exists (namespaces istio-enabled or default). Typical source cluster (e.g. cluster1) has that deployment; PNet, SEV-SNP or cluster2 often only have migrated vuln-spring-restore-* pods — those cannot be scaled with this control.
